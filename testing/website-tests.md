# Website Tests

## Navigation
1. Open the home page.
2. Go to an NBA, NFL, and MLB page.
3. Open at least one player page from each league.

## Search
1. Search for a full player name.
2. Search using a partial name.
3. Confirm the correct player page opens.

## Layout
1. Confirm player image loads.
2. Confirm bio text displays.
3. Confirm stats table appears.
4. Confirm no obvious alignment issues exist.

## Responsive Check
1. Test on desktop width.
2. Test on tablet width.
3. Test on mobile width.
